# Spell and particle gallery

The current gallery lives at builds/current/spell-gallery/index.html: 24 implemented spells and 28 configured particle-factory examples with a wizard reference. It now uses continuous native recordings, playable as 30fps video or downloadable 15fps GIFs. Search/filter, full-size inspection, frame stepping, seeking and slower playback support visual review. Opening a panel pauses the overview; closing pauses the detail view.

See [Visual workshop](VISUAL_WORKSHOP.md) for capture/export instructions and live renderer sizing controls. The older tools/capture_spell_gallery.gd remains a sparse-frame diagnostic tool writing builds/spell-stills; its output is not the animated gallery builder's input.
