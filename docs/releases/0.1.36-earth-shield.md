# 0.1.36 — Earth Shield and spell-family reference

Status: implemented on the 0.1.36 release branch; final verification and integration tracked in the pull request.

## Approved behavior

Each cast adds one stone charge. One incoming hit consumes one charge and is fully blocked before health or style penalties. Retaliation erupts toward the attacker, damaging and knocking enemies away along its visible path. Recasts stack independent charges. This replaces Earth Shield overheal; Earth Wall remains a separate future spell. This is intentional contact and counterattack, not a timed parry input.

## Provisional first-pass tuning

| Property | Value / rule |
|---|---|
| Charges | One per cast; no gameplay stacking cap; potency/geometry snapshot at cast |
| Charge lifetime | 16 s independently; Duration scales; recasting does not refresh existing charges |
| Damage | 60 base; +15% per spell rank; global Power applies |
| Geometry | 160 world-unit reach, 100° cone toward triggering attacker; Size scales reach |
| Knockback | 500 base, respecting existing enemy resistance |
| Propagation | Outward front over 0.22 s, then short visual fade; effect and hit region agree |
| Velocity | No effect |
| Consumption | One attack consumes one charge; remaining unblocked contact damage is batched for the existing single style penalty per contact tick |
| Combo | Successfully blocked hits do not apply hit penalties; later unprotected hits still do |

These numbers are tuning proposals for the authorized implementation, not previously agreed balance targets. Generic legacy overheal may remain for other callers; Earth Shield must no longer route through it.

## Required verification

- Melee and projectile sources determine the retaliation direction; unrelated enemies behind the caster are not hit.
- One charge catches one event, including a lethal hit; zero charges allows normal health/style loss.
- Charges expire independently; recast, Duration and own-rank behavior preserve that rule.
- Visible expanding cone matches damage/knockback timing and extent; each enemy hit once per eruption.
- UI shows charges rather than bonus HP; upgrade text describes actual benefits.
- Existing combinations, casting, style and unrelated healing remain valid.

## Documentation and scope

The [element × family matrix](../expedition-design/16-element-family-matrix.md) includes 16 current bases and seven enabled combinations, user ideas and explicit unselected examples. Arcane Seed and Arcane Shield are not agreed spells. Seed, Ball, Golem and Restoration are vocabulary/design decisions, not new runtime spells.

Next: playable tutorial and significant multiplicative keywords, then spell preparation, tower and expeditions. Keep style and the current fun roguelike while integrating those increments. Keep the friend’s art; discuss 2D/3D/hybrid direction later. No keyword parser, campaign, new elemental spells, art replacement or encounter-balance change belongs to 0.1.36.

Charge presentation shows up to twelve floating plates plus the exact charge count and next expiry in the casting reference. This visual limit does not cap protection. Spell and workshop previews trigger the real block/eruption path.

Verification evidence is retained locally in `builds/earth-shield-0136/`: runtime and preview tests, native desktop/narrow captures, documentation checks and deliberately incorrect combo/direction controls. Human balance testing remains necessary; this is a provisional tuning pass.
